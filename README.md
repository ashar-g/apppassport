# AppPassport

**From onboarding to governance — one passport for every application.**

Ready for GitHub check-in and Vercel deployment.

## Stack
- Next.js
- NextAuth
- Okta OIDC
- Vercel

## Deploy
1. Push to GitHub
2. Import into Vercel
3. Configure Okta environment variables
4. Deploy

- Application Registry
- IAM Onboarding Factory
- Governance Dashboard
- Risk & Compliance
- AI Assistant
